# Dynamic File Chunker

A complete, beginner-friendly Python project that splits any user-selected file into smaller binary `.bin` chunks with structured JSON metadata.

See the complete documentation and code in [`file_chunker/`](file:///c:/Users/Vasu%20lakhani/OneDrive/Desktop/Divide/file_chunker) or read [`file_chunker/README.md`](file:///c:/Users/Vasu%20lakhani/OneDrive/Desktop/Divide/file_chunker/README.md).

## Quick Start

```bash
# Run the interactive CLI:
python file_chunker/main.py

# Run the automated tests:
python -m unittest discover -s file_chunker/tests -v
```
